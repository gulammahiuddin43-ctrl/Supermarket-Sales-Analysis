**Student:** Gulam Mahiuddin  
**Dataset:** [SUPER MARKET DATA(3).xlsx](SUPER%20MARKET%20DATA%283%29.xlsx)

## Project Description
A Python-based exploratory data analysis project using the provided 500-row supermarket transaction dataset.

## Objectives
- Calculate sales KPIs.
- Analyze city/branch, product/category, monthly, payment and customer performance.
- Validate data quality and the `Sales = Quantity × Unit Price` relationship.
- Create reproducible visualizations and business insights.

## Technologies
Python 3, Pandas, NumPy, Matplotlib, OpenPyXL and Jupyter Notebook.

## Required Submission Files
1. `GulamMahiuddin_SupermarketSalesAnalysis.ipynb`
2. `requirements.txt`
3. `GulamMahiuddin_SupermarketSalesAnalysis_ProjectReport.docx`
4. `README.md`

## Setup / Run
1. Keep `SUPER MARKET DATA(3).xlsx` in the same folder as the notebook.
2. Run `pip install -r requirements.txt`
3. Run `jupyter notebook`
4. Open `GulamMahiuddin_SupermarketSalesAnalysis.ipynb`
5. Run all cells from top to bottom.
